03 · The gate

The gate

Every section passes seven checks.

1Values at the three widths
2A width in between
3No sideways scroll
4Text matches
5Images load, with alt text
6Lines break the same
7Render beside Figma
any row fails → fix → re-run all seven

✓ All seven pass — and only then does the next section start.

05 · What it improves

Honest position

What it improves, and what it can’t.

What it improves

Text matches

Diffed against Figma. Lines must break on the same word.

AVIF · 2–4× · alt text

No raster reaches the build unconverted.

rem and em only

One root value scales the whole page.

Behaviour in Webflow

Custom code only where the target can't.

Design system first

116 variables and 23 components before any page.

Components + variants

Six with variants and props registered.

What isn’t proven yet

Webflow
Proven — everything measured was built here
Plain HTML
Part-proven — one section only

Not targets — new work, not untested work

Not addressed at all

Never run — no by-hand comparison exists
