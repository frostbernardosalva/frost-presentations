Colour hierarchy

One blue, one black, one white.

The site is disciplined about colour: a near-black canvas, white type, and a single saturated blue reserved almost entirely for calls to action. Everything else is a tint or a grey.

Three different blues are in play, so they are kept distinct. The site’s variable set declares bright-blue: #0569FF; every button on the live page actually computes to #0B1464; and the brand primary is #0B1464, set by Frost. Only the last is normative — the other two are recorded because the live site still shows them.

Typography

Sailec, five weights, tight tracking.

One family does everything — display, body, navigation, labels. There is no second face and no mono. Display sizes carry negative tracking; body copy sits at normal.

Components

Pill geometry, hairline structure.

The component language is narrow and consistent: one button shape, underline form fields, almost no borders or shadows. Radius is either a full pill or nearly nothing.

Generated with the design-system skill (github.com/robonuggets/design-system, MIT) from one reference: the live site at frostdesigngroup.com. Colours were read from computed styles on the rendered page and from the site's stylesheet variable set; type sizes were measured on real elements; the mark is the site's own inline SVG.

Set, not extracted: the primary #0B1464 is Frost’s own design decision, applied here on request. Every other value in this document was taken from the live site.

Not included: design principles. The site does not publish any, and the toolkit's rule is to drop a section rather than invent one.
